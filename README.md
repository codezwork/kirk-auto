# Kirk Auto

Kirk Auto dealership website built with [Astro](https://astro.build/).

## Features
- Modern, responsive automotive dealership showcase
- Inventory browsing & vehicle detail pages
- Financing & trade-in payment estimator
- Contact & test-drive scheduling

## Getting Started

### Prerequisites
- Node.js (v18.17.1 or higher)
- npm

### Installation

```bash
npm install
```

### Development

To start the local development server:

```bash
npm run dev
```

### Production Build

To build the static site:

```bash
npm run build
```

To preview the build:

```bash
npm run preview
```
